アルゴリズムの説明

READMEの内容をデモ画面向けに整理した要約です。

処理概要

  1. 入力信号をリングバッファに格納し、Hann窓を適用してFFTを実行する。
  2. 各binに対してPhase Vocoderの水平位相更新を実行する。
  3. 周波数方向の位相整合として、垂直位相補正を適用する。
  4. IFFT後に窓掛けとOLAを行い、時間領域へ再合成する。

垂直位相補正仕様

目的

  • 隣接bin間の位相関係を保持する phase locking の一種。
  • ピーク追跡やbin分類は行わず、全binに同じルールを適用。
  • リアルタイム処理を想定し、分岐を抑えたコスパ重視の設計。

処理手順

  1. 位相勾配の抽出 
    V[k] = (X[k] * conj(X[k-1])) / |X[k] * conj(X[k-1])|
  2. 隣接bin提案の生成 
    P_below = H[k-1] * V[k]
P_above = H[k+1] * conj(V[k+1])
  3. 合意ベクトルの算出 
    C[k] = H[k] + w_b * P_below + w_a * P_above
  4. 位相反映（振幅保持） 
    Y[k] = |X[k]| * C[k] / |C[k]|

実装上の特性

  • 終端bin処理は if 分岐ではなく index/mask で吸収し、最適化しやすくする。
  • ピーク検出なしで全binに同一処理を適用し、複雑さを下げる。
